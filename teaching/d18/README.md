# D18 Assessment Shell module

This module is a presentation/read-projection layer over the accepted D17 Assessment domain. It must not become authoritative for Package scope, Attempt lifecycle, Response truth, device ownership, expiry/finalization, invalidation, marking, Gradebook, eligibility, SKM or model routing.

All browser mutations continue through D17 intents. D18 owns renderer contracts, shell presentation, local recovery UX, navigation/review projection, server-save posture, device-transfer presentation and network/timer projection only.
