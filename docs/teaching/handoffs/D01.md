## 6. Availability/configuration amendment

D01 originally introduced generic Teaching feature flags under TCH-0029 and TCH-0675.

A later accepted Class-E product amendment on 2026-09-25 supersedes that behavior:

- Teaching is a normal authenticated KIWI application surface.
- No per-user development allowlist controls Teaching availability.
- No generic runtime on/off flag controls high-stakes marking, impromptu tests, resits, external integrations, or future Teaching feature presence.
- Unimplemented capabilities remain absent until their owning delivery implements and accepts them.
- Implemented capabilities are available normally subject to their real academic/runtime prerequisites.

The removed runtime toggle names are:

- `TEACHING_ENABLED`
- `TEACHING_DEV_USER_IDS`
- `TEACHING_HIGH_STAKES_MARKING_ENABLED`
- `TEACHING_IMPROMPTU_TESTS_ENABLED`
- `TEACHING_RESITS_ENABLED`
- `TEACHING_EXTERNAL_INTEGRATIONS_ENABLED`

AI provider/model configuration remains an opaque operational configuration seam in `teaching/config/`; it is not a product availability switch. Teaching feature/domain code still does not call provider SDKs.

D30 empirical route qualification and D31 final release readiness remain mandatory safety/quality gates and are not feature toggles.

## 7. Security/secret changes

D01 audited Teaching/runtime code paths for hard-coded secrets and privileged browser credentials.

Changes:

- database connection source fallback removed from active `index.js`;
- hard-coded admin-token fallback removed;
- WebSocket JWT fallback removed;
- runtime secrets are resolved through `services/runtime-secrets.js`;
- Teaching security test rejects database URL literals, secret environment fallbacks and provider SDK imports.

Render production was configured with server-only `KIWI_DATABASE_URL` before merge as a compatibility alias. D01 resolves `DATABASE_URL` first, then `KIWI_DATABASE_URL`. No database credential is sent to either frontend.

Historical Git history still contains the previously committed database credential. Rotation remains an operational security follow-up; D01 removed it from active source and did not expose its value in the handoff.
